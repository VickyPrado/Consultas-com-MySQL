# Consultas-com-MySQL
Projeto criado referente ao curso Consultas com MySQL para aprendizado da linguagem com o banco de dados de código aberto MySQL, desenvolvendo habilidades para criar e gerenciar bancos de dados, manipular dados através de procedimentos armazenados, utilizar as funções nativas e criar funções personalizadas.

Scripts criados utilizando a linguagem:
> MySQL

IDE utilizada:
> MSQL Workbench 8.0 CE

Instalação pelo:
> XAMPP Control Panel
